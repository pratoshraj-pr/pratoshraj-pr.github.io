# PR Logs

> Personal technical blog — [pratoshraj-pr.github.io](https://pratoshraj-pr.github.io)

Built with **Quarto** (math/content rendering) + **Hugo** ([PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme) + **GitHub Pages** (hosting).

---

## Stack

| Layer | Tool |
|---|---|
| Content authoring | Quarto `.qmd` with MathJax LaTeX |
| Site generation | Hugo + PaperMod theme |
| Hosting | GitHub Pages (`gh-pages` branch) |
| CI/CD | GitHub Actions (auto-deploy on push to `main`) |

---

## Local development

### Prerequisites

```bash
brew install hugo quarto
```

### Install the PaperMod theme (first-time only)

```bash
git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
git submodule update --init --recursive
```

### Render Quarto sources → Hugo posts

```bash
cd quarto && quarto render . && cd ..
```

### Run the local dev server

```bash
hugo server -D
```

Visit [http://localhost:1313](http://localhost:1313).

## Writing a new post

1. Create `quarto/<post-slug>.qmd` with Hugo front matter at the top:

   ```yaml
   ---
   title: "My Post Title"
   date: 2024-MM-DD
   draft: false
   tags: ["tag1", "tag2"]
   math: true          # set to false if no LaTeX
   ---
   ```

2. Write your content in Markdown with `$...$` / `$$...$$` LaTeX.

3. Run `cd quarto && quarto render .` — the rendered markdown lands in `content/posts/`.

4. Commit and push to `main`. GitHub Actions handles the rest.

---

## Deployment

Push to `main` → GitHub Actions:
1. Installs Quarto & Hugo
2. Renders `.qmd` files to `content/posts/`
3. Builds the Hugo site to `public/`
4. Deploys `public/` to the `gh-pages` branch

GitHub Pages serves from the `gh-pages` branch at `https://pratoshraj-pr.github.io`.
